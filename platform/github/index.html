Where is GitHub blocked?

GitHub is blocked, restricted or age-gated in 9 countries and territories — 3 complete bans and 6 partial restrictions in total.

Crimea

Partial restriction Since: 2019 In force GitHub docs

GitHub restricts access to private repositories and commercial services for developers in the Crimea region to comply with US sanctions.

Islamic Republic of Iran

Partial restriction Since: 2019 In force GitHub blog

North Korea

Complete ban Since: Forever Reported Wikipedia

People's Republic of China

Partial restriction Since: 2013 Reported Wikipedia

Subject to intermittent DNS poisoning and blocks. GitHub Gist is permanently blocked, while the main site is often heavily throttled.

Russia

Partial restriction Since: 2014 Reported

Roskomnadzor frequently orders ISPs to block specific repositories that violate Russian law. The entire site has faced temporary blocks as a result.

Syria

Partial restriction Since: 2019 In force GitHub docs

GitHub restricts access to private repositories and commercial services for developers in Syria to comply with US sanctions.

Turkmenistan

Complete ban Since: Ongoing Reported DevActivity

GitHub, including its API, is completely blocked under the state's broad internet censorship, forcing developers to rely on VPNs to access the platform.
